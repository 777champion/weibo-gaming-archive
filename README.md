
# WEIBO GAMING ARCHIVE

**北京 WBG 第七代核心首發——博七時期紀錄網站**

## 專案簡介

WEIBO GAMING ARCHIVE 是一個以第五人格職業聯賽（IVL）北京 WBG 分部為主題的粉絲紀錄網站。

本專案聚焦於 2025 年 5 月至 2026 年 5 月的「博七」時期，記錄五位核心首發選手 Huiyi、Guoker、Persica、Koting 與 N1e 共同征戰的賽事歷程、重要時刻與競技成果。

網站希望透過選手介紹、賽事紀錄、時間軸與榮譽整理，保存這段共同奮戰的歷史。

本網站為獨立粉絲專案，並非 WEIBO GAMING 或第五人格職業聯賽官方網站。

## AI 開發規則

本專案使用 `AGENTS.md` 作為 AI 開發指引，內容包含：

- 專案目的與主題範圍
- 網站設計風格與視覺規範
- 各頁面的用途與內容規則
- 新增頁面與內容的方式
- 檔案命名及圖片管理規則
- 資料查證與歷史準確性要求
- AI 修改程式碼時的注意事項
- GitHub Pages 部署規範

當需要新增頁面或修改內容時，AI 應先閱讀 `AGENTS.md`，再依照既有架構與規則進行開發，以維持整個網站的一致性。

未來可以依照專案規則新增選手資料、賽事紀錄、重要時刻或其他相關頁面，而不必每次重新定義網站風格與開發方式。
